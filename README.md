# Human-in-the-Loop AI Action Approval Gateway

Deliver a controlled API gate for agent-proposed sensitive actions: policy risk decisions, scoped human approvals, expiry, replay protection, audit and safe execution.

An Inkplain practical case: a real project built step by step.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inkplain-Practical-Cases/practical--human-in-the-loop-ai-action-approval-gateway.git
cd practical--human-in-the-loop-ai-action-approval-gateway
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
